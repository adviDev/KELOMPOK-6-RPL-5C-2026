# KELOMPOK-6-RPL-5C-2026
Tema Proyek : Sistem Izin Masuk Perpustakaan Menggunakan RFID

Perpustakaan Politeknik Negeri Pontianak (Polnep) merupakan fasilitas vital yang melayani kebutuhan referensi dan belajar bagi ribuan mahasiswa. Sebagai pusat layanan kampus, efisiensi dalam pencatatan kehadiran pengunjung menjadi hal yang sangat penting.

Namun saat ini, proses pendataan kehadiran pengunjung masih memicu antrean di meja layanan pada jam-jam sibuk. Selain itu, perekaman data secara manual atau kurang terintegrasi menyulitkan pengelola perpustakaan dalam mengumpulkan dan menyusun statistik kunjungan secara real-time .

Untuk mengatasi permasalahan tersebut, diusulkan Sistem Izin Masuk Perpustakaan Polnep Menggunakan RFID . Sistem ini difokuskan secara spesifik untuk menangani izin masuk dan rekapitulasi statistik kunjungan (tidak termasuk peminjaman buku maupun denda). Sistem ini mengintegrasikan pemindaian kartu RFID dengan simulasi berbasis layar ( software alert dan buzzer ), di mana proses pendaftaran kartu RFID dilakukan secara otomatis oleh Admin Perpustakaan guna menjamin keamanan dan validitas data.
